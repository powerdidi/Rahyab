# ره‌یاب مشهد — گام ۱: صفحه منو

پیاده‌سازی پایتونی پروتوتایپ حمل‌ونقل عمومی مشهد با **Flask**.
در این گام فقط صفحه منو (خانه / Bento Grid) ساخته شده است؛ بقیه بخش‌ها
(مسیریاب اتوبوس، مسیریاب ترکیبی، اسکن QR، نقشه شبکه) در گام‌های بعد اضافه می‌شوند
و فعلاً با پیام «این بخش در گام‌های بعد ساخته می‌شود» پاسخ می‌دهند.

## ساختار پروژه

```
mashhad-rahayab/
├── app.py              # اپ Flask + مسیر صفحه خانه
├── requirements.txt    # وابستگی‌ها (فقط Flask)
├── static/
│   ├── style.css       # سیستم طراحی (نئومورفیسم) — مشترک بین همه صفحات
│   └── app.js          # JS مشترک: ساعت، تیکر، toast، ناوبری
└── templates/
    ├── base.html       # قاب موبایل + dock + هاست toast/sheet/map
    └── home.html       # صفحه منو (Bento Grid)
```

ساختار عمداً ساده نگه‌داشته شده: یک قالب پایه، یک فایل CSS مشترک، یک فایل JS مشترک.
در گام‌های بعد، برای هر صفحه یک قالب و یک مسیر Flask اضافه می‌شود و از همین
قالب پایه و CSS/JS مشترک استفاده می‌کند.

## اجرا در VSCode

۱) پوشه پروژه را در VSCode باز کنید:

```bash
cd mashhad-rahayab
code .
```

۲) محیط مجازی بسازید و Flask را نصب کنید:

```bash
python -m venv venv
source venv/bin/activate        # در ویندوز: venv\Scripts\activate
pip install -r requirements.txt
```

۳) برنامه را اجرا کنید:

```bash
python app.py
```

۴) در مرورگر باز کنید:

```
http://127.0.0.1:5000
```

## نکات

- صفحه خانه از دو بخش پویا تشکیل شده: **ساعت/تاریخ زنده** (سمت کلاینت) و
  **نوار اعلان‌ها (ticker)** که داده‌اش از مسیر Flask به قالب تزریق می‌شود.
- داده اعلان‌ها فعلاً در `app.py` به‌صورت نمونه (`SAMPLE_NOTICES`) قرار دارد.
  در گام‌های بعد این داده از وب‌سرویس واقعی دریافت می‌شود.
- آیکون‌ها از CDN `lucide` بارگذاری می‌شوند (مثل پروتوتایپ اصلی)؛ برای اجرا
  به اینترنت نیاز است.
- دکمه‌های dock و کاشی‌های منو برای بخش‌های هنوز‌ساخته‌نشده، فقط یک toast نمایش می‌دهند.
